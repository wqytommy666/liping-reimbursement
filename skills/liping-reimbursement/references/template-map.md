# 附件1 Excel 与 附件2 Word 代填说明

**核心原则**：不要让老师或同学自己手动打开 Excel 或 Word 去填表！凡是票据里能识别的字段全部自动填入；凡是票据里没有的文字信息（如学号/工号、经费项目号、报销收款人、自驾车牌号、驾驶员、往返里程等），直接在对话框里请对方发文字过来，**由 Agent 代填进 Excel 和 Word 并生成好文件**，对方只需最后打印签字。

## 一、附件1《报销材料清单.xlsx》填写位置

模板 `assets/附件1-报销材料清单.xlsx` 保留原件，复制副本填写。以下地址是初始模板位置；插行后重新定位，不继续硬编码。

| 位置 | 含义 | 填写规则 |
| --- | --- | --- |
| Sheet1!A1:N1 | 标题（合并） | 保留 |
| B2:H2 | 出差事由（合并） | 真实人员、地点、会议/事由和起止日期替换示例 |
| B3:D3 / G3:H3 | 出差人1工号/学号 / 姓名 | 号码用文本，保留前导零 |
| B4:D4 / G4:H4 | 出差人2 | 同上 |
| B5:D5 / G5:H5 | 出差人3 | 同上 |
| 第6行 | 更多人员示意 | 按需扩展，不用时清除省略号 |
| A7:N7 | 行程及费用列名 | 保留 |
| A8:N10 | 行程示例 | 清掉示例填真实行程；不足在合计前插行并复制格式 |
| A11 / B11:D11 | 合计费用金额 / 金额 | 明细计算，缺关键金额时标待补并另外列已知小计 |
| A12 / B12:D12 | 报销收款人1 | 只填确认收款人，不默认等于出差人或付款人 |
| A13 / B13:D13 | 报销收款人2 | 同上 |
| 第14行 | 更多收款人示意 | 按实际处理 |

第7行：A出差起点；B出差终点；C起；D迄；E天数；F飞机票；G火车票；H汽车票；I其他交通费；J住宿费；K会务费；L其他费用；M伙食补贴；N交通补贴。

模板为A4横向，没有公式。金额存数值，日期用真实日期值，格式适当。不要保留 `***`、`**省**市`、2026年7月示例日期、`……` 为业务数据。

## 易错点

- 第8行7月12日至13日写2天，第9行7月13日至15日也写2天。它不是明确制度；不能推导首尾均计或跨段重复计算。区分自然日、停留天数和补助计发天数。口径待确认时E列和补助列标待定。
- 多人费用只记一次真实票据，注明分摊；不按人数重复乘整票金额。
- 改签退票保留原票、新票、退款和手续费关系，申请金额核实净支出及适用口径。
- 未知/待补不能当0；无此费用和不适用应区别说明。
- 通知要求票据张数和支付对应关系，主表无专用字段。保留主表，增加“票据与支付明细”工作表。

## 明细表

每张唯一票据一行：票据ID、费用类别、人员/行程段、票种及号码、日期、开具方、币种、票面金额、申请金额、支付ID、关联支付金额、支付文件/页码、备注、原文件/页码。

多对多关系可在同表下方列支付ID、票据ID、分摊金额、备注。支付本身列真实时间、金额、收款方、付款人和方式；不把一笔支付总额复制给每张发票重复合计。

分类汇总列唯一票据张数、金额；票据额、已知申请小计、补助、退款及最终申请总额构成能追溯。保存后重算并验证公式和显示，缺项保持可见。明细表是落实通知要求的整理方式，不是另有校方强制模板。

## 二、附件2《电子科技大学出差车辆行驶登记表.docx》Word 代填位置

当涉及自驾或租车报销时，复制 `assets/附件2-电子科技大学出差车辆行驶登记表.docx`，使用 `python-docx` 将从票据识别到的信息及用户在对话中提供的车牌号、驾驶员、行驶里程等直接填入表格第 0 张表（`doc.tables[0]`）：

| 单元格坐标 `(row, col)` | 字段名称 | 代填规则 |
| --- | --- | --- |
| `(0, 1)` | 出差人 | 填入真实出差人姓名 |
| `(0, 3)` | 所在单位 | 填入学院/单位名称（如 `信息与通信工程学院`） |
| `(1, 1)` | 行驶方式 | 根据实际情况填 `☑自驾车           □租车` 或 `□自驾车           ☑租车` |
| `(2, 1)` | 车辆信息 | 填入 `车牌号：<车牌号>           驾驶员：<驾驶员姓名>` |
| `(3, 1)` | 日期 | 填入 `YYYY 年 MM 月 DD 日 至 YYYY 年 MM 月 DD 日   共 N 天` |
| `(4, 1)` | 目的地 | 填入出差目的地 |
| `(5, 1)` | 行车路线 | 填入具体往返路线（如 `成都—绵阳—成都`） |
| `(6, 1)` | 行驶费用 | 填入 `行驶里程数：<里程> Km\n  汽油费：<金额> 元\n  其他费：<过路费/租车费等> 元` |
| `(7, 1)` | 审批意见 | 保留 `审批人：\n年    月    日` 供打印后签字 |

> 注意：该 Word 表格第 1～7 行的第 1、2、3 列为合并单元格，填写 `(row, 1)` 即可更新整行内容，填写时保持原有字体与字号。

## 三、《情况说明》代写规则

当存在以下情形时，由 Agent 直接根据真实行程与用户在聊天中确认的信息生成排版整齐的《情况说明》（Word 或直接转 A4 PDF 编入材料册），用户只需打印签字：
1. **邀请方承担食宿**：无需向邀请方索要证明，报销时不报销对应食宿费用，直接写明“本人于 YYYY年MM月DD日至MM月DD日赴XX参加XX会议，会议期间食宿由邀请方承担，本次差旅报销不申领相关食宿费用。特此说明。”并留出“说明人（签字）：”及日期栏。
2. **行程变更 / 往返不闭合 / 中转 / 改签退票**：根据用户告知的实际原因写清每一段行程的时间、起止地与原因，留出本人签字栏。
